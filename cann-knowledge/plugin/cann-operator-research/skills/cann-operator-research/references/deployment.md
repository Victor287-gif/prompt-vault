# 独立 MCP 的部署边界

知识包已经包含只读 MCP 源码、索引构建脚本、测试与安装说明（可重建数据库不随 ZIP 分发）。普通查询优先使用现有 GitHub MCP；这不要求部署新服务器。

本 Skill 包没有伪造远程 MCP 地址，也不会自动启动持久服务。专用服务器可用 stdio 或 Streamable HTTP（默认只绑定 127.0.0.1），网页连接仍需已授权的安全隧道/托管和认证。

部署时读取仓库中的 `cann-knowledge/docs/MCP_SETUP.md` 与 `cann-knowledge/requirements.txt`，核对当前版本后执行。只在用户明确要求部署时操作，不把“选中 Skill”解释为设备执行、权限变更或开放端口授权。

本入口仅查询公开知识；比赛源码和 OJ 记录继续从用户授权的工程连接读取，不上传到公共仓库。
