# CANN 算子研究知识库

在 ChatGPT 中选择本插件的 `cann-operator-research` Skill，直接描述需要研究的算子问题即可。

已有 GitHub 连接即可访问已发布资料，不要求本地电脑在线。专用知识 MCP 接入后可使用全文检索。

这是基于官方来源的独立知识接入封装，不是 CANNBot 官方发布的 ChatGPT 插件，不承诺与其他模型相同的能力。

知识包位置：https://github.com/Victor287-gif/prompt-vault/tree/cann-knowledge-v1/cann-knowledge

本插件默认只读。编译、设备实验、部署服务器、修改算子和 OJ 提交需要另行明确的任务授权。
