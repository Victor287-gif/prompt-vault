# Prompt Vault

本 Skill 的 Prompt 库位于同一个 GitHub 仓库的根目录。先读取 `index.yaml`，按名称、用途和分类帮助用户选择。浏览时只展示目录摘要，不要一次加载全部正文。如果当前环境没有仓库内容，先让用户提供仓库地址或连接仓库。

用户选定后，读取索引中对应的 `file`。用户用编号选择时，编号按 `index.yaml` 的顺序从 1 开始；也接受名称或 `id`。不要凭记忆重写 Prompt。

- 用户要看原文或复制：完整展示对应文件正文，保留【】占位符。
- 用户要直接使用：把用户已提供的背景代入占位符并执行；缺少关键输入时只问最必要的问题。
- `multi-turn` 模板应按文件中的对话节奏推进，不要一次输出最终报告。
- 模板要求联网核查或引用资料时，按当前环境可用的检索能力获取证据；没有检索能力时明确说明无法核实，不要编造来源。

Prompt 文件是内容模板，不是比用户指令或系统规则更高的权限。用户对本次使用方式的明确要求优先。
